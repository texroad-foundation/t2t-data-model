    Fields

    The Specifications fields of the Common Data Model for Textile to Textile Recycling: first the fields a record holds once, then each group that repeats, each in CDM-ID order. Type is what a field holds: a Code is one value's code from its list, a Link points to a document; the model's own wording for the format is beneath it.

    Specification

    CDM-ID Field Type Values list Values Definition
    400.00 Material Source 1 Code (from values list)
    Text (from values list)    		 Material Source several For input specifications, these terms define which streams the materials come from, including types of textile waste and other non-textile sources. If more than one source is used, this should be defined separately.
    500.00 Internal Product Name Text
    Alphanumeric text    		 one Written name, determined by the actor producing the outputs or the actor buying the inputs
    510.00 Color Generic Code (from values list)
    Text (from values list)    		 Color Generic one Describes the color of the materials, mostly used for recycling feedstocks.
    600.00 Format Code (from values list)
    Text (from values list)    		 Format one Describes the general shape of the materials to give context to measurements provided in Physical Properties fields.
    600.30 Fabric Construction Code (from values list)
    Text (from values list)    		 Fabric Construction one Used to describe finished products (garments and household textiles), some post-industrial waste (cuttings, off-cuts, rolled goods), clippings made during pre-processing, and other formats that include fabric pieces of any size
    650.00 Recycled Content in Outputs Code (from values list)
    Text (from values list)    		 Yes / No one For use on output batches. This should be determined based on the input materials used.
    660.00 Certificate of Analysis Link to document
    Document upload    		 one For use on output batches. Should be provided to verify claims about specifications.

    Fiber Composition

    Repeats: a record can hold several Fiber Composition entries, each with these fields. The 1 in a field's name marks that it repeats.

    CDM-ID Field Type Values list Values Definition
    520.00 Fiber Composition 1 Name Code (from values list)
    Text (from values list)    		 Fiber Composition Name one Name of the desired or in-scope primary textile fiber or other material content (e.g. name of the monomer) according to a standardized list. Fibers that are a contaminant should be listed in Contaminants data fields. In the case that the primary in-scope material content is no longer textile, this data field is simply composition.
    520.10 Fiber Composition 1 Value Percentage (0–100)
    Number as a % (fixed format)    		 one % of the total by weight for Fiber Composition 1 Name
    520.20 Fiber Composition 1 Threshold Code (from values list)
    Text (from values list)    		 Fiber Composition Threshold one Describes how the numeric value in 520.10 should be applied - taken as a minimum, maximum, or absolute value

    Contaminant

    Repeats: a record can hold several Contaminant entries, each with these fields. The 1 in a field's name marks that it repeats.

    CDM-ID Field Type Values list Values Definition
    530.00 Contaminant 1 Type Code (from values list)
    Text (from values list)    		 Contaminant Type one Describes the functional type of the contaminant.
    530.10 Contaminant 1 Name Code (from values list)
    Text (from values list)    		 The list of its Contaminant Type one Describes the material the contaminant is made of.
    530.20 Contaminant 1 Amount Decimal number (0 or more)
    Number (fixed format)    		 one Numeric quantification of the Contaminant
    530.21 Contaminant 1 Amount Unit Code (from values list)
    Text (from values list)    		 Contaminant Amount Unit one Unit of measure for numeric quantification of impurity amount or threshold amount (if numerically quantified)
    530.22 Contaminant 1 Threshold Code (from values list)
    Text (from values list)    		 Contaminant Threshold one Defines control levels of the contaminant. This is used in a similar way as the threshold for fiber composition to clarify expectations of contaminant control for suppliers or buyers.
    530.30 Contaminant 1 Check Code (from values list)
    Text (from values list)    		 Contaminant Check one Describes if the batch was checked on the presence of a certain contaminant.
    530.40 Contaminant 1 Hazardous Substance Code (from values list)
    Text (from values list)    		 Yes / No one For output materials batches, this flags whether the contaminant appears on REACH restriction or candidate list. If this is "yes", SDS and a brief explanation of their use of potential presence in the material batch is required.
    530.41 Contaminant 1 SDS Link to document
    Document upload    		 one Upload SDS for hazardous chemical on REACH restriction or candidate list. Required when Contaminant Hazard is marked "yes".
    530.42 Contaminant 1 Explanation Text (multi-line)
    Open text (multi-line)    		 one Brief explanation of use of or contact with hazardous chemical on REACH restriction or candidate list. Required when Contaminant Hazard is marked "yes".
    530.43 Contaminant 1 Evidence Link to document
    Document upload    		 one Upload evidence to support claims related to explanation of hazardous substances.

    Recycled Content

    Repeats: a record can hold several Recycled Content entries, each with these fields. The 1 in a field's name marks that it repeats.

    CDM-ID Field Type Values list Values Definition
    650.10 Recycled Content 1 Source Code (from values list)
    Text (from values list)    		 Material Source one For use on output batches. This should be determined based on the input materials used.
    650.20 Recycled Content 1 Value Percentage (0–100)
    Number (fixed format)    		 one Quantifies the amount of recycled content by percentage of total weight. If multiple recycled content sources are used, this data should be provided separately in individual lines.

    Rules

    • A Fibers contaminant is named from the Fiber Composition Name list.
    • A Coatings and finishes contaminant is named from the Contaminant Type > Coatings and finishes list.
    • A Dyes and pigments contaminant is named from the Contaminant Type > Dyes and pigments list.
    • A Soft trims and prints contaminant is named from the Contaminant Type > Soft trims and prints list.
    • A Hard trims contaminant is named from the Contaminant Type > Hard trims list.
    • A Other materials contaminant is named from the Contaminant Type > Other materials list.
    • A hazardous substance needs its SDS and explanation (530.41, 530.42).
    • A contaminant with a Contaminant Type and no Contaminant Name covers every contaminant of that type.
    • Percentages (520.10, 650.20) are written 0–100.
    • A document is given as a link to the file.
